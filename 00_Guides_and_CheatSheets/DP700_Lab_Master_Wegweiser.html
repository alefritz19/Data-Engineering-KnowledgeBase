TEIL 2: Das Ingenieur-Lexikon (Die wichtigsten Begriffe auf Deutsch & Russisch)

Begriff Was bedeutet das in der Praxis? Значение для дата-инженера (RU)
OneLake Ein zentraler Data Lake für das gesamte Unternehmen („OneDrive für Daten“). Basiert auf ADLS Gen2. Единый океан данных компании. Все службы (Spark, SQL, BI) читают один источник без дублирования.
Lakehouse vs Warehouse Lakehouse: Python/Spark + Files + Tables (SQL nur lesend).
Warehouse: Reines T-SQL, Lese- und Schreibzugriff, Stored Procedures, ACID-Transaktionen.		 Lakehouse: для Python, Spark и сырых данных (Bronze/Silver).
Warehouse: для реляционной аналитики, процедур T-SQL и витрин.
Delta Lake (_delta_log) Open-Source-Speicherformat. Kombiniert Parquet mit einem Transaktionsprotokoll. Ermöglicht ACID, Versionierung und Time Travel. Формат хранения: сжатый Parquet + журнал транзакций. Дает откат версий и надежность банковского уровня.
Z-Order & Optimize Fasst kleine Dateien zusammen (Bin-Packing) und sortiert Daten physisch nach Spalten für File Skipping. Оптимизация файлов: склеивает мелкие файлы и сортирует строки, ускоряя запросы в десятки раз.
Schema Shortcut (Verknüpfung) Ein Zeiger auf ein Schema oder eine Tabelle in einem anderen Lakehouse. 0 Byte kopiert. Символическая ссылка (Zero-Copy): таблица видна в Gold, но физически лежит в Silver.
Headless Pipeline Automatischer Batch-Lauf im Hintergrund. Startet Notebooks ohne Benutzeroberfläche nach Zeitplan. Пакетный запуск блокнота вслепую (фоном) по расписанию через оркестратор Data Factory.
CTAS CREATE TABLE ... AS SELECT: Erstellt und befüllt eine neue Tabelle in einem einzigen T-SQL Befehl. Создание физической таблицы на основе SQL-запроса одной командой.
Stored Procedure Gespeicherte T-SQL Prozedur im Warehouse. Kann mit EXEC name; jederzeit aufgerufen werden. Хранимая процедура на сервере: запускается одной командой из скрипта или пайплайна.

4. Zelle 1 (PySpark Transformation): 
from pyspark.sql.functions import col, to_date, year, date_format, coalesce, lit

# 1. Aus Bronze einlesen
df_raw = spark.read.table("lh_bronze.dbo.publicholidays")

# 2. Bereinigen & Typisieren
df_silver = df_raw \
    .filter(col("date") >= "2020-01-01") \
    .withColumn("HolidayDate", to_date(col("date"))) \
    .withColumn("Year", year(col("HolidayDate"))) \
    .withColumn("DayOfWeek", date_format(col("HolidayDate"), "EEEE")) \
    .withColumn("IsPaid", coalesce(col("isPaidTimeOff"), lit(False))) \
    .select(
        col("countryRegionCode").alias("CountryCode"),
        col("countryOrRegion").alias("CountryName"),
        col("holidayName").alias("HolidayName"),
        col("HolidayDate"),
        col("Year"),
        col("DayOfWeek"),
        col("IsPaid")
    )

# 3. In Silver als Delta speichern
df_silver.write.format("delta").mode("overwrite").saveAsTable("lh_silver.dbo.dim_holidays")
print("Silver erfolgreich geschrieben!")
5. Zelle 2 (Delta Maintenance & Z-Order): 
%%sql
OPTIMIZE lh_silver.dbo.dim_holidays ZORDER BY (HolidayDate);
DESCRIBE HISTORY lh_silver.dbo.dim_holidays;
6. Ausführen (Play ▶). Ergebnis: dim_holidays existiert in lh_silver mit 3 Versionen im Log.

6 Fabric Warehouse & T-SQL Cross-Database Queries
1. Im Workspace auf + Neues Element $\rightarrow$ Warehouse $\rightarrow$ Name: wh_analytics.
2. Links im Explorer auf + Warehouses klicken $\rightarrow$ lh_silver ankreuzen (damit die Tabellen sichtbar werden).
3. Oben auf Neue SQL-Abfrage klicken $\rightarrow$ CTAS-Tabelle erstellen: 
CREATE TABLE dbo.Country_Holiday_Summary AS
SELECT 
    CountryCode, CountryName,
    COUNT(*) AS TotalHolidays,
    SUM(CAST(IsPaid AS INT)) AS PaidHolidays,
    MIN(HolidayDate) AS FirstDate,
    MAX(HolidayDate) AS LastDate
FROM [lh_silver].[dbo].[dim_holidays]
GROUP BY CountryCode, CountryName;
4. Stored Procedure erstellen: 
CREATE OR ALTER PROCEDURE dbo.usp_Refresh_Holiday_Summary
AS
BEGIN
    TRUNCATE TABLE dbo.Country_Holiday_Summary;
    INSERT INTO dbo.Country_Holiday_Summary
    SELECT 
        CountryCode, CountryName,
        COUNT(*) AS TotalHolidays,
        SUM(CAST(IsPaid AS INT)) AS PaidHolidays,
        MIN(HolidayDate) AS FirstDate,
        MAX(HolidayDate) AS LastDate
    FROM [lh_silver].[dbo].[dim_holidays]
    GROUP BY CountryCode, CountryName;
END;
5. Testausführung: EXEC dbo.usp_Refresh_Holiday_Summary; $\rightarrow$ 38 Zeilen aktualisiert in 2 Sekunden!
